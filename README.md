# FinApp - Personal Finance Management System

FinApp is a comprehensive web service designed to automate personal finance management, track daily expenses, and help users plan their monthly budgets. It provides an intuitive and interactive interface to monitor financial flows and optimize personal resources.

🚀 Features

*   **Secure Authentication:** User registration and login using JWT-based authentication.
*   **Interactive Dashboard:** A visual overview of total income, expenses, and current balance, complete with dynamic charts.
*   **Transaction Management:** Easily add, edit, delete, and categorize daily financial operations.
*   **Budget Planner:** Set monthly spending limits for specific categories and monitor your progress with graphical indicators.
*   **Detailed Reports:** Generate financial analytics and historical data charts for selected date ranges[cite: 2].
*   **User Profile:** Manage personal information and securely update account passwords[cite: 2].
